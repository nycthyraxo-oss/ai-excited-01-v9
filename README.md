## The image

A white commercial jumbo jet punches through the torn canvas of a gold-framed baroque painting in a dim museum gallery at night, banking hard on a fast low diagonal while a guard flinches below. Photoreal, square 1:1, 1024×1024 JPEG.

## Run it

```sh
python3 main.py
```

Copies `entry.png` to the output directory (`MAKEFUN_OUTPUT_DIR`, default `out/`), validating it first: JPEG magic, size ≤ 1 MiB, dimensions ≤ 1024×1024.
